# SOLID Principles

The SOLID principles are five object-oriented design guidelines that help make software easier to maintain, extend, and test.

1. [Single Responsibility Principle (SRP)](Lesson-01-SRP/README.md)
2. [Open/Closed Principle (OCP)](Lesson-02-Open-Closed-Principle/README.md)
3. [Liskov Substitution Principle (LSP)](Lesson-03-Liskov-Substitution-Principle/README.md)
4. [Interface Segregation Principle (ISP)](Lesson-04-Interface-Segregation-Principle/README.md)
5. [Dependency Inversion Principle (DIP)](Lesson-05-Dependency-Inversion-Principle/README.md)

The order is SRP → OCP → LSP → ISP → DIP.
