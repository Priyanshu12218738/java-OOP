## Suggested Lesson Deliverables

For each concept or pattern, maintain:

- **Concept notes:** Intent, problem solved, structure, trade-offs, and when to use it.
- **UML:** Class diagram and sequence diagram where relevant.
- **Java implementation:** Small, focused examples.
- **Practical use case:** A realistic scenario.
- **Trade-offs:** Benefits, drawbacks, and alternatives.
- **Practice:** Review questions or a small coding task.

For each machine-coding project, maintain:

1. Functional and non-functional requirements.
2. Core use cases and actors.
3. Entities, enums, and interfaces.
4. Class diagram and important sequence diagrams.
5. Working Java implementation.
6. Edge cases and validation.
7. Test cases and design review.
