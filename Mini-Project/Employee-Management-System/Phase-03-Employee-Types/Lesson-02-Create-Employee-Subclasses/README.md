# Lesson 2 — Create Employee Child Classes

**Status:** ✅ Passed

## Objective
Create `PermanentEmployee`, `ContractEmployee`, and `InternEmployee` as subclasses of `Employee`.

Each class:
- Uses `extends Employee`.
- Defines a constructor with employee ID, name, email, and department.
- Calls `super(employeeId, name, email, department)`.

All three submitted class skeletons were reviewed as correct. The learner also correctly understood that a child class cannot directly access the parent's private fields; it should use accessible methods such as getters.
