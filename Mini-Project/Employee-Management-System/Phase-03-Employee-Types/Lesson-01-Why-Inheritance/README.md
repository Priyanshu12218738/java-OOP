# Lesson 1 — Why Do We Need Inheritance?

**Status:** ✅ Concept check passed

## Objective
Understand why common employee data belongs in a shared parent class.

Permanent, contract, and intern employees share:
- Employee ID
- Name
- Email
- Department

Keeping common state in an `Employee` parent class avoids repeating those fields in each employee type.

## Knowledge check
The learner correctly selected `extends` as the Java keyword for class inheritance.
