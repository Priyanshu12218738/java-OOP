# Lesson 5 — Display Attendance

**Phase:** 5 — Attendance Management  
**Status:** 🟡 Solution walkthrough

## Objective
Display all attendance records belonging to a selected employee.

## Implementation Outline
- Accept an employee ID.
- Iterate through the attendance list.
- Display only records whose employee ID matches the requested ID.
- Track whether any record was found.
- If none were found, display a clear no-records message.

## Important Detail
The found flag distinguishes an employee with attendance records from an employee for whom the list contains no matching records.
