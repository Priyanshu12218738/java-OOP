# Employee Management System

**Module:** Mini Projects  
**Project type:** Java Console Application  
**Design focus:** OOP, SOLID, Low Coupling, High Cohesion

## Objective
Build an Employee Management System covering employee records, employee types, salary calculation, attendance, notifications, monthly payroll, and reports.

## Project Modules

| Module | Responsibility |
|---|---|
| Employee Management | Add, update, remove, and view employee records |
| Salary Calculation | Calculate salary using employee-specific rules |
| Attendance | Track present and absent days |
| Notifications | Send notifications through multiple channels |
| Payroll | Generate monthly payroll and prevent duplicates |
| Reporting | Generate employee, attendance, and salary reports |

## Learning Rules
- Implement the Java code yourself.
- Work one lesson at a time and submit code/output for review.
- Do not treat a design walkthrough as proof that implementation was independently completed.
- Keep pending corrections visible even when a phase has been declared complete.
